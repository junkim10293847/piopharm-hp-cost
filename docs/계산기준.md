# 계산 기준

## 매출 구분
- **평택 매출** = 평택 로트목록 로트의 출하금액 × 평택비율
  - 평택비율(생산구분): 평택 100%, 화성포장 80%, 멀티연질 60%, 정제화성 20%, 화성 0% — `--ratio`로 변경 가능
- **화성 매출** = 출하대장 전체 − 평택 매출
  = 로트목록에 없는 출하 + 평택 로트의 화성분(1 − 평택비율)
- 출하금액은 출하대장 `공급가액`, 매칭 키는 **제품코드 + 로트번호**

## 원가 (재료원가 = 원료 + 자재)
- 원료 = 단가대장에서 자재코드가 `3…`(반제품)인 금액 + 주정(`4C00000149`)
- 자재 = 제품 제조금액 합계 − 원료
- 단가대장은 품목코드가 `1…`(제품)인 행만 씁니다.

### 평택 로트
1. **원가월**: 자재투입현황의 로트 제조월 단가대장을 쓰고, 없으면 그다음 달 대장을 씁니다.
2. **배분**: 같은 제품·같은 원가월 로트끼리 완료수량 비율로 제품 원가를 나눕니다.
3. 로트 원가 = 제품 원가 × 배분비율 × 평택비율 × 보정계수
4. 수주수량·단가는 발주현황에서 `매출 월 = 당월` 행만 씁니다. 제품코드가 달라 매칭이 안 되면 로트번호로만 찾고 확인사항에 표시합니다.
5. 규격(mg, 캡슐/포 수, set ea)은 작업지시현황 규격 문자열에서 해석하고, 생산중량 → set 수량 → 조정비율(생산 set ÷ 수주수량)로 원료원가·부자재원가를 냅니다.
6. 수율 = 생산중량 ÷ 투입중량 (같은 투입번호는 한 번만 합산)

### 화성 품목
- 원가 = 출하중량 × (원가월 단가대장 제품 제조금액 ÷ 생산중량)
- 원가월 = 당월, 없으면 가장 가까운 이전 달
- 원료·자재는 그 제품 단가대장의 원료 비율로 나눕니다.
- 제품 코드(`1…`)가 아니거나 단가대장에 없으면 원가를 비워 두고 확인사항에 표시합니다.

## 기존 수식 시트 대비 바뀐 점
| 항목 | 기존 | 변경 |
|---|---|---|
| 발주현황 범위 | 고정 행범위 `$B$2075:$AE$2331` | `매출 월 = 당월` 조건 |
| 조회 키 | 로트번호 단독 | 제품코드 + 로트번호 |
| 같은 제품 여러 로트 | 첫 로트에 원가 몰아주기 | 완료수량 비율 배분 (합계 동일) |
| 전월 로트 원가월 | 행마다 수작업 선택 | 제조월 → 없으면 다음 달 자동 |
| 규격 | 수기 입력 | 작업지시 규격 문자열 자동 해석 |
| 수율 | 투입중량 중복 합산(49%·24%) | 투입 1건당 1회 (97% 내외) |
| 보정계수 | 원료에만 곱함 → 차액이 자재로 | 원가 전체에 곱함 |
| 화성 매출·원가 | 없음 | 출하대장 나머지 + 출하중량 기준 원가 |
