# 계산 기준

> **v3.0 (2026-11-19)** 출하 기준 통일·이월 검토를 더했습니다(아래 v3.0 절). v2.0 절은 그대로 유효하고, 그 아래는 v1 기록입니다.

## v3.1 추가 기준 (2026-11-19)

- **선출하(익월 생산분을 먼저 출하).** 보관함에 익월 로트목록이 있고 그 로트가 이번 달 출하대장에 있으면, 출하일 기준으로 이번 달 평택 매출이다(작업지시가 화성이어도 익월 로트목록의 생산구분·평택비율을 따른다). 원가는 생산월 단가대장으로, 생산월 대장에 없고 당월 대장에 그 제품 투입액이 있으며 당월 로트가 쓰지 않으면 당월 투입액으로 계산한다.
- **다음 달 처리.** 전월 출하대장(보관함)에 이미 출하된 로트는 잔량에서 빼고 「선출하 → 재고 아님」으로 표시한다. 이월 계산도 생산 전달 출하를 뺀다.
- **제품코드 오타.** 로트목록 제품코드가 출하대장과 다르면(10S↔1OS, 10B24↔1OB34 등), 같은 로트의 출하대장(없으면 작업지시) 제품코드가 하나뿐일 때 그 코드로 맞추고 원본 확인 표시를 남긴다. 한 글자 로트는 O·0만 다를 때만 맞춘다.
- **다른 달 대장에만 있는 제품**(예: 8월 로트목록의 1952C001이 7월 대장에만 있음)은 쓰지 않고 금액만 알려 준다. 생산귀속을 입력하면 그 달 대장으로 계산한다.

## v3.0 추가 기준 (2026-11-19)

- **매출 = 출하 기준.** 출하대장 출고일자가 당월인 출하의 공급가액만 매출로 잡는다. 수주단가 × 수주수량(가공 파일 V열)은 쓰지 않는다.
- **로트번호 맞추기.** 출하대장이나 로트목록에 로트번호를 `1726C003-1`처럼 나눠 적었고 상대편에 원래 로트만 있으면 원래 로트로 맞춘다. 같은 출하 로트에 여러 행이 맞춰지면 완료수량 비율로 나눠 한 출하를 두 번 세지 않는다. 9월 가공본(1020)도 평택 1,528,496,411원으로 미가공과 같다.
- **로트목록 「전월」 구역**은 당월 로트가 아니라 전월 생산 출하로 분류하고, 원가는 생산월 단가대장으로 계산한다.
- **이월 검토.** 이월 수량 = 보관함 이전 달 로트목록 완료수량 − 생산월부터 전달까지 출하대장 출하량. 이번 달 출하와 함께 상태(전량·일부·계속 이월)와 반영처, 생산월 원가를 보여 준다. 중간 달 출하대장이 없으면 이월 수량을 정하지 않는다.

## v2.0 현재 기준 (2026년 9월 가공 파일과 원 단위 대조로 검증)

| 항목 | 기준 |
|---|---|
| 로트 찾기 | 항상 제품코드 + 로트번호. 로트 이름을 -1/-2로 고치지 않아도 됨 |
| 평택비율 | 로트목록 생산공장/포장공장: 평택/평택 100%, 평택/화성 80% (기존 생산구분 텍스트도 그대로 읽음) |
| 평택 당월 매출 | 로트 출하금액(출하대장 공급가액) × 평택비율 |
| 평택 당월 원가 | 출하량 × (당월 단가대장 제조금액 ÷ 같은 제품 로트들의 생산수량 합) × 평택비율. 생산수량 = 완료수량과 출하량 중 큰 값. 출하 안 된 수량은 잔량(재고) |
| 당월 단가대장에 없는 로트 | 생산월 단가대장 kg당 제조금액 × 출하중량. 생산월은 로트목록 생산귀속 월(당월 목록 또는 보관함의 이전 달 목록)로만 정함. 없으면 원가 빈칸 (v2.1: 작업지시 날짜로 추정하지 않음) |
| 평택 전월 생산 출하 | 로트목록에 없지만 작업지시번호 10-30 또는 출하 현장 비오팜2공장 → 매출 100% 평택, 원가 = 출하중량 × 생산월 단가대장 kg당 제조금액 (생산월은 이전 달 로트목록 생산귀속) |
| 제품 단가 대장 | 그 달 마감의 생산 투입액. 마감월(시트 이름의 월) 기준으로 저장, 작업일자가 다른 행은 알림만 |
| 화성 | 나머지 출하, 원가 = 출하중량 × 당월 단가대장 kg당 제조금액. 당월 대장에 없으면 빈칸 |
| 원료 / 자재 | 원료 = 반제품(3…) + 주정(4C00000149), 자재 = 나머지 |
| 미출고 재고 | FCO 제품(1…) 현재고 > 0, 공장은 작업지시번호로 구분. 재료비 열은 로트목록 당월 생산 잔량에만 표시(비례 추정 없음) |
| 쓰지 않는 것 | 조정비율, 규격 문자열 해석, 자재투입현황 로트 조회(수율), 발주현황 고정 범위 |

9월 검증: 평택 당월 매출 1,266,840,527 / 재료원가 590,912,835(원료 440,800,480·자재 150,112,355), 전월 생산 출하 261,655,884, 평택 합계 1,528,496,411, 화성 4,610,146,990, 평택 미출고 기말 제품재고(FCO) 502,780,199.

단가대장 금액은 재료비 기준이고 FCO 금액은 가공비 포함 원가로 보여 두 금액은 서로 다릅니다.

## v1 기록

## 매출 구분
- **평택 매출** = 평택 로트목록 로트의 출하금액 × 평택비율
  - 평택비율(생산구분): 평택 100%, 화성포장 80%, 멀티연질 60%, 정제화성 20%, 화성 0% — `--ratio`로 변경 가능
- **화성 매출** = 출하대장 전체 − 평택 매출
  = 로트목록에 없는 출하 + 평택 로트의 화성분(1 − 평택비율)
- 출하금액은 출하대장 `공급가액`, 매칭 키는 **제품코드 + 로트번호**

## 원가 (재료원가 = 원료 + 자재)
- 원료 = 단가대장에서 자재코드가 `3…`(반제품)인 금액 + 주정(`4C00000149`)
- 자재 = 제품 제조금액 합계 − 원료
- 단가대장은 품목코드가 `1…`(제품)인 행만 씁니다.

### 평택 로트
1. **원가월**: 자재투입현황의 로트 제조월 단가대장을 쓰고, 없으면 그다음 달 대장을 씁니다.
2. **배분**: 같은 제품·같은 원가월 로트끼리 완료수량 비율로 제품 원가를 나눕니다.
3. 로트 원가 = 제품 원가 × 배분비율 × 평택비율 × 보정계수
4. 수주수량·단가는 발주현황에서 `매출 월 = 당월` 행만 씁니다. 제품코드가 달라 매칭이 안 되면 로트번호로만 찾고 확인사항에 표시합니다.
5. 규격(mg, 캡슐/포 수, set ea)은 작업지시현황 규격 문자열에서 해석하고, 생산중량 → set 수량 → 조정비율(생산 set ÷ 수주수량)로 원료원가·부자재원가를 냅니다.
6. 수율 = 생산중량 ÷ 투입중량 (같은 투입번호는 한 번만 합산)

### 화성 품목
- 원가 = 출하중량 × (원가월 단가대장 제품 제조금액 ÷ 생산중량)
- 원가월 = 당월, 없으면 가장 가까운 이전 달
- 원료·자재는 그 제품 단가대장의 원료 비율로 나눕니다.
- 제품 코드(`1…`)가 아니거나 단가대장에 없으면 원가를 비워 두고 확인사항에 표시합니다.

## 기존 수식 시트 대비 바뀐 점
| 항목 | 기존 | 변경 |
|---|---|---|
| 발주현황 범위 | 고정 행범위 `$B$2075:$AE$2331` | `매출 월 = 당월` 조건 |
| 조회 키 | 로트번호 단독 | 제품코드 + 로트번호 |
| 같은 제품 여러 로트 | 첫 로트에 원가 몰아주기 | 완료수량 비율 배분 (합계 동일) |
| 전월 로트 원가월 | 행마다 수작업 선택 | 제조월 → 없으면 다음 달 자동 |
| 규격 | 수기 입력 | 작업지시 규격 문자열 자동 해석 |
| 수율 | 투입중량 중복 합산(49%·24%) | 투입 1건당 1회 (97% 내외) |
| 보정계수 | 원료에만 곱함 → 차액이 자재로 | 원가 전체에 곱함 |
| 화성 매출·원가 | 없음 | 출하대장 나머지 + 출하중량 기준 원가 |
